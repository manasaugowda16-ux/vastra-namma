# Namma Vastra 🧵✨

A Weaver-to-Market Trend Guide & Saree Shopping Platform connecting traditional artisans of Ilkal and Molakalmuru with modern connoisseurs.

## 🌟 Key Features
- **Identity-First Entry**: Tailored workflows for **Master Weavers** (production tools, fair price calculator, and trend insights) and **Artisan Curators/Customers** (exclusive product discovery and shopping cart).
- **Artisanal Catalog**: Browse heritage sarees with high-resolution image carousels, detailed artisan notes, and fabric specifications.
- **Fair Price Calculator**: Transparent financial ledger tool designed to empower weavers.
- **Market Intelligence**: Real-time city fashion insights and trending color boards.
- **Secure Checkout & Invoicing**: Simulated order completion with instant receipt and order summary downloads.

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend & Database**: Firebase Firestore
- **Platform**: Google AI Studio Integration
